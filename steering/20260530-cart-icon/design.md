# カートアイコン + 商品数バッジ 詳細設計書（フロントエンド）

## 概要

ヘッダーにカートアイコンを表示し、カート内の合計商品数をバッジで示す。  
アイコンをクリックするとカートページ（`/cart`）へ遷移する。

---

## 画面設計

### 配置

`Header` コンポーネント内、ログアウトボタンの左隣。

```
┌─────────────────────────────────────────────────┐
│ Admin | STORE        商品管理    🛒²  ログアウト→ │
└─────────────────────────────────────────────────┘
                                  ↑
                             カートアイコン + バッジ
```

### バッジ仕様

| 状態 | バッジ表示 |
|---|---|
| カートが空（0個） | 非表示 |
| 1〜9個 | 個数をそのまま表示（例: `3`） |
| 10個以上 | `9+` と表示（桁あふれ防止） |

---

## 状態管理

カートの中身は `useCartStore`（Zustand）から取得する。

```ts
const cart = useCartStore((state) => state.cart);
const cartCount = cart.reduce((sum, item) => sum + item.count, 0);
```

- `cart` は `CartItem[]`（`productId`, `price`, `name`, `stock`, `count`）
- `cartCount` は全商品の `count` の合計値（商品種類数ではなく個数の合計）
- カートに変更があると Zustand が自動的に再レンダリングを走らせるため、常に最新の個数が表示される

```
ヘッダーのカートアイコンクリック
  └── カートページ（/cart）へ遷移
```

---

## 実装詳細

### アイコン

SVG アイコン（ショッピングバッグ）をインラインで使用。外部ライブラリは使わない。

### バッジ

アイコンを `relative` で配置し、バッジを `absolute -top-2 -right-2` で重ねる。

```
[アイコン relative]
  └── [バッジ absolute -top-2 -right-2]
```

### バッジのスタイル

- 背景: `bg-white`（ヘッダーの `bg-zinc-900` に対して目立つ白）
- 文字: `text-zinc-900`、`text-xs`、`font-bold`
- 形状: `w-4 h-4 rounded-full`（円形）
